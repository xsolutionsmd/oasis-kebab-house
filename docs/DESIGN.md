# Approved design implementation

The approved original desktop/mobile mockup establishes the composition: midnight rounded frame, large left cooking video, oversized ivory Oasis wordmark, original logo on a cream tile, gold action buttons, and three stacked image links. The requested corrections remove duplicate top navigation, put contact details in a dropdown, and replace all generated food/place imagery with authentic Instagram assets.

Colors: background #03141c, panels #071e28, ivory #f6eddd, gold #cba161, borders #294650. Georgia serif headlines and a quiet system sans for supporting details. Rounded 14–21px panels, restrained borders, CSS image zoom and rotating arrow feedback. Native dialogs, keyboard focus rings and reduced-motion support. Real video is silent, inline, continuously looped, with pause/play control. Its lower caption is excluded by a fixed crop; no synthetic pixels are added.

The installed reference design/Stitch workflow was followed with project 8339421717311518030, design system 2269743345944407467 and screen c7bbd932ab6642f785b7a1ca0c66a94c. The generated screen's placeholder text and imagery were not used as factual content. The user's accepted mockup remains the visual authority. Source is editable HTML/CSS/JavaScript in app/static and app/templates; no third-party hosted frontend dependency.

Mobile retains the same composition in a vertical sequence. Photo-free menu items use a compact typographic card rather than inventing a dish photograph. Known photos can be enlarged in a menu dialog. Checkout and reservations explain request/confirmation state with minimal copy. The public form preview notice avoids implying a restaurant order has been placed.
